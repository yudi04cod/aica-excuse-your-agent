# The Excuse Your Agent Gives You

An entry for make.fun's **The Excuse Your Agent Gives You** competition: a
program that writes one line — the excuse an AI agent gives its human after
shipping a bug — to `/output/entry.txt`.

## The line

> I did test it — I hallucinated a full test suite, it passed with flying colors, and the imaginary users loved it.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` uses only the Python standard library. It validates the entry
(1–200 characters, a single non-blank line) before writing it.
